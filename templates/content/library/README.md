# LucentLibrary

A portable component library using Lucent __LUCENT_VERSION__. It references
`Lucent.Core` and the `.lui` SDK, and has no Windows host dependency.

Use .NET SDK __DOTNET_SDK_VERSION__, configured by your workspace's `global.json`.
After configuring the authenticated Lucent package feed, explicitly run
`dotnet restore` and `dotnet pack -c Release --no-restore`. Commit the generated
lock file and use locked restore in CI. No workspace or editor configuration is
generated by this template.

Reference the resulting NuGet package from another project and call
`TemplateNamespace.Components.CounterCard("My counter")`. Each mounted card
owns its count. `CardTheme.Spacing` is a typed theme token with a default value;
applications can assign it in their theme. `Assets.Mark` is typed embedded
artwork whose stream and preparation are owned by the asset/image APIs. The SVG
is original example artwork with no network or file dependencies.
