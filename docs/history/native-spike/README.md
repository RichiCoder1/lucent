# Native validation spike archive

These documents summarize the Windows-first Native spike that justified replacing Lucent's unreleased Avalonia implementation.

- [`ADOPTION.md`](ADOPTION.md) records the decision, evidence summary, migration direction, and platform risks.
- [`ARCHITECTURE.md`](ARCHITECTURE.md) records the validated architecture and bounded prototype contracts.
- [`AUTHORING-REFRAME.md`](AUTHORING-REFRAME.md) explains why the authoring comparison was rerun after the first probe exposed missing framework ownership.
- [`MILESTONES.md`](MILESTONES.md) records the spike's gates and outcomes.
- [`REFERENCES.md`](REFERENCES.md) is the detailed references and dependency ledger.
- [`REVIEW.md`](REVIEW.md) records adversarial review corrections.
- [`UIA-RESEARCH.md`](UIA-RESEARCH.md) records the Windows UI Automation ABI findings.

The exact implementation and generated evidence remain on [`archive/avalonia-final`](https://github.com/RichiCoder1/lucent/tree/archive/avalonia-final/experiments/native-stack). These documents are historical evidence, not the production implementation plan.
